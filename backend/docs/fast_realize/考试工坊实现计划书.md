## 一、业务范围（v2 修正后）

**系统只负责**：用户输入（提示词 或 文档）→ **出卷子智能体**按试卷模板用 LLM 直接生成试卷 + 参考答案 → 导出 **PDF / Word / MD** 文件。

**明确不做**（v2 删除）：题库管理、题目查重、审核流、组卷策略、考试组织、成绩、指派、AI 出题审核——相关数据表全部不建。

**核心设计**：
- **试卷模板定义在提示词中**：prompts.yml 内置 3 个试卷模板（通用安全知识 / 法规条文 / 事故案例），决定题型分布、题量、分值、格式要求
- **出卷子智能体**：在现有 `llm_client`（LangChain ChatOpenAI，DeepSeek 主 / agnes 降级，读 .env）之上封装"出卷专家"，不引入新框架
- **知识来源**：RAG 知识库（**只引用** `hybrid_retrieve` 只读调用）+ LLM 自身记忆
- **导出依赖已确认**：python-docx 1.2.0 ✅ / reportlab 4.4.10 ✅ / md 零依赖 —— 全部可用

**并行开发约束（铁律）**：考试工坊与 RAG 优化迭代在另一会话并行——**绝不改动** `src/ai/rag.py`、`embeddings.py`、`knowledge.py`、`reranker.py`、`prompts.py` 任何 RAG 相关代码；prompts.yml **仅追加**新模板条目，不动现有 RAG 条目。

## 二、数据层（仅 1 张新表）

### `exam_papers`（试卷生成记录表，对齐 ppt_tasks 模式）

| 列 | 类型 | 说明 |
|---|---|---|
| id | INT PK 自增 | |
| paper_id | VARCHAR(32) UNIQUE | 业务标识 `paper_`+uuid12，导出文件名/详情路由用 |
| title | VARCHAR(128) | 试卷名称 |
| template | VARCHAR(32) | 试卷模板 key（对应 prompts.yml 模板） |
| input_type | ENUM(prompt,document) | 输入类型：提示词 / 上传文档 |
| input_text | TEXT NULL | 提示词或文档提取文本（≤5000 字截断） |
| input_file | VARCHAR(255) NULL | 上传的源文档路径（md/txt） |
| exam_content | LONGTEXT NULL | **生成的试卷结构 JSON**（题目数组，含参考答案与解析） |
| export_format | ENUM(md,docx,pdf) | 导出格式（下载时按需渲染，此处记录最近一次） |
| file_path | VARCHAR(255) NULL | 最近导出文件路径（uploads/exam/ 相对路径） |
| status | ENUM(draft,generating,done,failed) | 状态机：草稿→生成中→已完成/失败 |
| error | VARCHAR(255) NULL | 失败原因 |
| created_by | INT FK→users | 创建人 |
| created_at / updated_at | DATETIME | |

状态机：`draft → generating → done / failed`（对齐 ppt_tasks：草稿→生成中→已完成/失败）。

**落地**：追加到 `database/schema.sql` → MySQL 建表 → `models/exam_paper.py`（对齐现有模型风格）→ `models/__init__.py` 导出 → `scripts/db_verify.py` 增加该校验。

## 四、导出设计

### 新文件 `src/services/exam_export.py`

| 函数 | 输出 | 实现 |
|---|---|---|
| `to_md(exam_json) -> str` | Markdown | 标题 + 题型分组 + 题干/选项/答案/解析，模板渲染 |
| `to_docx(exam_json, path)` | Word | python-docx：Document + 标题/分组/题目段落/答案（加粗） |
| `to_pdf(exam_json, path)` | PDF | reportlab：A4 + UnicodeCIDFont("STSong-Light") 中文字体，逐题排版 |

- 文件落盘 `uploads/exam/{paper_id}.{ext}`（对齐 ppt 的 `uploads/` 模式）
- `main.py` 挂载 StaticFiles：`/exam-files` → `uploads/exam`（对齐 ppt-files 静态托管，路径以实际部署为准，**不硬编码端口**）

## 五、API 设计（精简后，复用现有分层）

| 方法 | 路径 | 功能 | 权限 |
|---|---|---|---|
| GET | /exam/templates | 试卷模板列表（prompts.yml） | 登录 |
| POST | /exam/papers | **生成试卷**（title/template/input_type/input_text 或文件上传/use_rag/export_format）→ 同步返回任务（含 exam_content） | 登录 |
| GET | /exam/papers | 我的试卷历史（分页） | 登录 |
| GET | /exam/papers/{paper_id} | 试卷详情（内容 JSON + 状态） | 登录（本人） |
| POST | /exam/papers/{paper_id}/export | 按格式导出（body: format）→ 生成文件并返回下载 URL | 登录（本人） |
| GET | /exam-files/{filename} | 静态下载导出文件 | 登录 |

- 文件上传复用现有 `utils/files.py`（校验扩展名 md/txt，大小 ≤2MB）
- 删除/重新生成不做（v2 范围外，历史记录保留即可）
