## 一、改了什么（问题 → 做法 → 结果）

| # | 问题 | 做法 | 结果 |
|---|---|---|---|
| 1 | PPT 产物按主题命名，跨任务/跨账号互相覆盖（ISO-1） | 命名改为 `u{user_id}_t{task_id}_{主题}.pptx`，命名逻辑抽成 `PptService._artifact_dest()` | 同主题两个任务落到两个文件，互不覆盖 |
| 2 | `/ppt-files/*` 静态无鉴权，可猜可枚举（ISO-2） | 取消静态挂载；新增 `GET /api/ppt/{task_id}/download`（JWT + `_get_owned` 归属校验） | 无 token 401、他人 403、本人 200 |
| 3 | 试卷导出有两条无鉴权静态通道（ISO-3） | 导出目录 `uploads/exam/` → `exam_files/`（移出 uploads）；取消 `/exam-files` 挂载；新增 `GET /api/exam/papers/{id}/download`；中间件封 `/uploads/exam/**` 为 403 | 老静态路径 404 / 403；下载只走鉴权端点 |
| 4 | 历史产物不能因改造而取不到（裁定 4） | 下载端点按数据库 `file_path` 定位：PPT 取 basename 再拼产物目录；试卷做「新目录 → uploads/exam」两段兼容解析 | 历史 3 个 pptx + 1 套试卷均可下载（实测 200） |
| 5 | 前端 `<a href>` 无法携带 `Authorization`（D-1） | 两处下载改 `api()` + `blob()` + `createObjectURL`；PPT 下载名取主题，试卷下载名取服务端 `Content-Disposition` | 真机点「下载/导出」均成功落盘，文件名是业务名 |
| 6 | 模板共享被误判为缺陷（ISO-4） | **不改代码**，在规划文档 ③ 段写明「团队共享模板库，有意为之」 | — |
| 7 | `routers/exam.py` docstring 端点清单不符（ISO-5） | 同步改为 6 个端点（含新增下载端点） | `/docs` 与 docstring 一致 |
| 8 | 产物目录不在忽略清单 | `.gitignore` 增 `backend/ppt_files/`、`backend/exam_files/` | 产物不入库 |

## 四、偏差与事故（如实记录）

| # | 偏差/事故 | 说明 |
|---|---|---|
| D-a | **命名逻辑抽成 `_artifact_dest()`** | 方案里是内联在 `generate()` 中的三行；实施时抽出静态方法，因为内联无法单测「两账号同主题路径不同」。行为等价，可测性更好 |
| D-b | **PPT 路径解析比方案更严** | 方案写「basename + 白名单」；实现只取 basename（`Path(file_path).name`）后拼目录，数据库里 `../` 完全无效，比白名单校验更早失效。单测 `test_ppt_download_path_traversal_blocked` 守护 |
| D-c | **试卷下载名改用服务端 header** | 方案写「下载名用试卷标题」；因为 `<a download>` 已被 Blob 方案替代，改为服务端 `Content-Disposition` 下发，前端解析（UTF-8 优先，失败退回 `试卷.<fmt>`） |
| D-d | **探针初始假设错误（不改代码）** | 首个运行态脚本把 task 3 当成 admin 的，实测 403 后核对数据库：task 3 属 user 186。**403 本身恰好证明隔离生效**；随后改用 admin 名下的 task 7/10 复测 |
| D-e | **服务启动约 60 秒** | 本机 uvicorn 首次启动要 ~60s 才监听（依赖 import 扫描），阻塞式等待脚本需给足超时，否则报 `ERR_CONNECTION_REFUSED` |
| D-f | **ISO-6 根因定位（不修）** | 全量 pytest 挂起的原因锁定为 `tests/test_chat.py::test_chat_sse_flow`：该用例只 mock 了 `llm_client.chat_stream`，没有 mock `hybrid_retrieve`，于是真加载 bge/reranker 并访问 Chroma，**228.62 秒后**以 `chromadb.errors.InternalError` 失败。本大点「明确不做」已把它列为独立事项，此处只留证据 |
