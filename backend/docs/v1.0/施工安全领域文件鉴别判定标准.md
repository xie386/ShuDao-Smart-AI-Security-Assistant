# 施工安全领域文件鉴别判定标准

**用途**：知识文件上传模块的审核人员参考手册——判定一份上传文件是否属于"施工安全领域"知识，决定是否允许入库。

**版本**：v1.0 ｜ 依据：蜀道知识库污染清理实战经验（272 篇污染文件移除 + 73 篇通识保留的判定复盘）

---

## 1. 判定总原则

审核一份文件，按以下三条原则层层过滤：

1. **主体原则**：文件内容是否围绕"建筑施工/施工现场/施工企业/在建工程"的安全管理？
2. **通识原则**：若主体不是施工，是否属于"施工时必然用到的通用安全知识"（消防、职业健康、危化品贮存、特种设备、应急演练等）？——这类**保留**
3. **排他原则**：若主体是其他行业（校园、矿山、冶金、纯环保、国际公约等）且与施工无交叉——**拒绝**

> 一句话记忆：**"施工的"要，**"施工常用的"**也要，"其他行业的"不要。

---

## 2. 快速判定流程（决策树）

```
第 1 步：读标题 / 首行
   │
   ├─ 命中【施工安全核心词】→ ✅ 通过，按四类入库
   │
   ├─ 命中【明确排除词】→ ❌ 拒绝
   │
   ├─ 是"事故案例"类 → 走 5.4 事故案例专项判定
   │
   └─ 都不是 → 第 2 步
   
第 2 步：判断是否【施工常用通识知识】
   ├─ 是（消防/职业健康/危化品/特种设备/演练模板/班组管理）→ ✅ 通过
   └─ 否 → 第 3 步

第 3 步：边界模糊？
   ├─ 有施工可能性（无法仅凭标题判定）→ ⚠️ 转人工复核（见 §6）
   └─ 明确其他行业 → ❌ 拒绝
```

## 3. 关键词速查表

### 3.1 施工安全核心词（命中即通过）

**施工场景类**
施工、建筑、工地、在建、建设工程、工程项目、分部分项、危险性较大、房屋市政、市政工程、公路水运、高速公路、隧道、桥梁、基坑、深基坑、高支模、模板、脚手架、塔吊、起重、吊装、吊篮、龙门架、物料提升机、支护、临边、洞口、拆除、爆破作业

**作业类型类**
高处作业、高处坠落、高空、坠落、坍塌、触电、临时用电、施工用电、焊接、气割、有限空间、机械伤害、物体打击、车辆伤害、淹溺（施工场景）、突水突泥（隧道施工）

**管理类**
安全交底、三级安全教育、安全培训、安全检查、隐患排查、安全生产费用、安全标准化、特种作业、持证上岗、安全责任制、危大工程

**行业主体类**
施工企业、建设公司、建筑公司、项目部、施工单位、劳务分包、混凝土搅拌站（施工现场供应链）

### 3.2 明确排除词（命中即拒绝）

**其他行业主题**
校园、学校、中学、小学、幼儿园、宿舍（非施工）、矿山、煤矿、矿井、冶金、钢铁厂（非施工）、化工生产、港口作业（非施工）、海洋、渔业、农业、畜禽、食品加工、餐饮、商场、酒店（非施工场景）、景区、游乐设施

**纯环保/非安全主题**
环境质量、污染物排放监测、生态保护（与施工安全无关者）

**时效性低质内容**
征求意见稿、草案（未生效）、已废止、已作废、被修订（有现行有效版本时）、政策通知公告（无安全内容）、新闻宣传稿、营销推文

## 4. 四类文件的判定要点

上传文件按内容归入四类，各类有额外的判定维度：

### 4.1 法规/制度类（laws）

| 判定 | 说明 |
|------|------|
| ✅ 直接通过 | 施工安全法规/标准/规程：建设工程安全生产管理条例、建筑施工安全技术规范、危大工程管理规定、高处作业/临时用电/脚手架等专项规范 |
| ✅ 通识保留 | 通用消防法、职业病防治法、危险化学品贮存通则、特种设备规则、劳动防护标准——施工合规常依赖 |
| ⚠️ 版本优先 | 同一法规多版本时**只保留现行有效版**（如职业病防治法三版只留最新） |
| ❌ 拒绝 | 其他行业法规（煤矿安全规程、化工生产规范、校园安全条例等与施工无交叉者）；已废止/被修订旧版 |

### 4.2 应急预案类（plans）

| 判定 | 说明 |
|------|------|
| ✅ 直接通过 | 施工场景预案：危大工程应急预案、高处坠落/坍塌/触电专项预案、施工消防预案、防汛预案（施工工地） |
| ✅ 通识保留 | 通用火灾/消防应急演练预案、危化品泄漏预案（施工临时库房可用）、锅炉/压力容器/气瓶演练方案、通用应急演练模板 |
| ❌ 拒绝 | 行业专属预案：校园安全预案、矿山事故预案、化工港务预案、海洋溢油预案（非施工场景） |

### 4.3 操作规程类（procedures）

| 判定 | 说明 |
|------|------|
| ✅ 直接通过 | 施工工序操作规程：高处作业、脚手架搭拆、起重吊装、临时用电、有限空间作业、焊接气割、模板支架 |
| ✅ 通识保留 | 危化品泄漏/火灾现场处置方案、氧气乙炔/气瓶处置、电气火灾预防、通用消防知识、灭火器使用、班组管理（与施工班组交叉） |
| ❌ 拒绝 | 其他行业工艺规程：煤矿作业规程、化工生产工艺、冶金操作规程等 |

### 4.4 事故案例类（cases）——重点专项判定

事故案例最容易误判，按**"事故是否发生在施工场景"**判定：

**✅ 保留的事故特征：**
- **施工项目事故**：标题含"项目/工程/在建/标段"（如：渝昆高铁**在建项目**突水突泥、地铁**区间施工**淹溺、供排水**改造项目**事故）
- **施工企业事故**：主体是建设公司/施工企业（如：浙江铭诚**建设有限公司**车辆伤害）
- **施工工艺作业事故**：高处坠落、脚手架坍塌、塔吊倒塌、起重伤害、临时用电触电、有限空间作业中毒、基坑坍塌——**即使标题没写"施工"，只要是这些作业类型且发生在作业现场，判施工相关**
- **道路/隧道/桥梁施工**：公路养护工程、隧道不明气体爆炸、盾构区间事故
- **建筑维修/外立面作业**：公寓维修招牌触电（涉及高处+临电）

**❌ 拒绝的事故特征：**
- 其他行业事故：煤矿事故、化工生产事故、校园事故、景区事故、电厂管道爆炸（非压力管道施工场景）
- 纯交通事故（非施工车辆）：高速公路普通交通事故、城区道路交通事故（无施工背景）

**⚠️ 边界案例（转人工复核，见 §6）：**
- 渔光互补项目淹溺（是否水上光伏**施工**阶段）
- 排水管网运维公司淹溺（是否管道维护/清淤**施工**作业）
- 建材公司厂区车辆伤害（是否**施工现场**而非生产厂区）
- 高压蒸汽管道裂爆（是否覆盖压力管道**安装施工**）

## 5. 内容质量门槛（入库前硬性检查）

除领域判定外，文件须满足：

| 检查项 | 标准 |
|--------|------|
| 内容长度 | 有效正文 ≥ 2000 字符（过短视为碎片/无价值） |
| 标题规范 | 有明确标题（能看出主题）；纯"DB""@相关人员"等无意义标题需人工复核 |
| 内容完整 | 无大量乱码、HTML 残留、重复段落 |
| 时效性 | 现行有效（非征求意见稿/已废止） |

---

## 6. 边界案例复核要点

无法凭标题判定时，打开内容检查以下要点：

1. **看主体单位**：事故/作业发生在"施工企业、项目部、在建工地"还是"生产厂区、运营场所"？
2. **看作业性质**：是"施工作业"（搭拆、浇筑、吊装、开挖）还是"生产运行"（工厂生产、设备运营）？
3. **看工艺场景**：涉及脚手架/临边/基坑/吊装/临时用电等施工工艺特征词 → 判施工相关
4. **看通用性**：虽然是其他行业文件，但内容是否直接可被施工安全培训/预案引用（如通用消防口诀、演练模板）？→ 可引用则保留
5. **不确定就复核，复核仍不确定 → 按"宁缺毋滥"拒绝**（入库污染比漏收损失大——污染会拉低所有问答的精确率）

---

## 7. 判定结论与处置

| 结论 | 处置 |
|------|------|
| ✅ 通过 | 按内容归入四类之一入库（laws/plans/procedures/cases） |
| ⚠️ 复核 | 转人工，按 §6 要点二次判定 |
| ❌ 拒绝 | 不入库，可记录拒绝原因供用户知晓 |
