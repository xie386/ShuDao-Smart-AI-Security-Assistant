### 2.2 数据契约

**HazardCreate**（H01 上报）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| title | str | 2–128 字 | 隐患标题 |
| description | str | 5–2000 字 | 隐患描述 |
| level | str | `^(重大\|较大\|一般\|轻微)$` | 隐患等级（四级） |
| hazard_type | str? | ≤64 字 | 隐患类型 |
| location | str? | ≤128 字 | 位置 |
| image_urls | list[str]? | — | 上传接口返回的 url 列表 |

**AssignRequest**（H04）：`assignee_id`（必填）、`due_date`（可选，ISO 时间）。
**RectifyRequest**（H05）：`rectify_measures`（5–2000 字）、`rectify_images`（可选 list）。
**AcceptRequest**（H06）：`approved`（必填 bool）、`note`（可选 ≤500 字）。

**HazardOut**（隐患响应）：`id/title/description/level/hazard_type/location/status/reporter_id/assignee_id/due_date/image_urls/rectify_measures/rectify_images/created_at/updated_at`。
**HazardDetailOut** = HazardOut + `timeline[]`（`action/operator_id/note/created_at`）。
**HazardListOut** = `{total, page, page_size, items[]}`。

**ChatRequest**（A01）：`question`（1–2000 字）、`conversation_id`（可选，空=新建）、`title`（可选）。
**HazardStatsOut**（H07）：`{total, by_level, by_type, rectify_rate, pending, trend[]}`，其中 `trend` 固定 7 个点 `{date, created, closed}`。

## 3. 隐患状态机（测试前提）

合法流转（非法流转一律 `400`）：

```
待处理 ──派单──▶ 处理中 ──整改──▶ 待验收 ──通过──▶ 已闭环
                    ▲                       └──驳回──▶ 已驳回 ──重新派单──▶ 处理中
                    └────────────────────────────────────────────┘
```

权限顺序（先权限后状态机）：**RBAC（router 层）→ 业务权限（assignee 校验）→ 状态机校验**。

| 端点 | 权限 | 非法时返回 |
| --- | --- | --- |
| assign / accept | admin、safety_officer | 其他角色 `403` |
| rectify | 责任人本人 或 admin | 非责任人 `403` |
| 任意流转 | 状态机不匹配 | `400` |

## 4. 接口测试用例

### 4.1 POST /api/uploads/image — 图片上传

**用例 U-01 合法上传（201）**

| 项 | 值 |
| --- | --- |
| 前置条件 | 已登录，持有 `<token>` |
| 请求 | `curl --noproxy '*' -X POST $BASE/api/uploads/image -H "Authorization: Bearer <token>" -F "file=@test.jpg;type=image/jpeg"` |
| 预期状态码 | `201 Created` |
| 预期响应体 | `{"url":"/uploads/<32位hex>.jpg","message":"上传成功"}` |
| 校验点 | ① 状态码 201；② `url` 以 `/uploads/` 开头且扩展名正确；③ 静态访问 `GET $BASE{url}` 返回 200 且内容为原图 |

**用例 U-02 非法扩展名（400）**

| 项 | 值 |
| --- | --- |
| 请求 | 上传 `malware.exe`（MIME `application/x-msdownload`） |
| 预期状态码 | `400 Bad Request` |
| 预期响应体 | `{"detail":"不支持的图片格式: exe（仅允许 jpg/jpeg/png/webp）"}` |

**用例 U-03 MIME 与扩展名不符（400）**

| 项 | 值 |
| --- | --- |
| 请求 | 上传文件名 `fake.png` 但 MIME 为 `image/jpeg` |
| 预期状态码 | `400` |
| 预期响应体 | `{"detail":"文件类型与扩展名不符: image/jpeg"}` |

**用例 U-04 超过大小限制（413）**

| 项 | 值 |
| --- | --- |
| 请求 | 上传 >10MB 的 jpg |
| 预期状态码 | `413 Payload Too Large` |
| 预期响应体 | `{"detail":"图片超过大小限制 10MB"}` |

**用例 U-05 未登录（401）**

| 项 | 值 |
| --- | --- |
| 请求 | 不带 Authorization 头 |
| 预期状态码 | `401 Unauthorized` |
| 预期响应体 | `{"detail":"未提供认证令牌"}` |

### 4.9 POST /api/chat — A01/A03 SSE 流式问答

**用例 CH-01 SSE 流式 + 会话自动创建（200）**

## 7. 附录：D2 常见问题

| 问题 | 处理 |
| --- | --- |
| 上传后静态访问 404 | 确认图片已落盘 `uploads/`；`StaticFiles` 挂载在 `/uploads`，直接 `GET /uploads/<filename>` |
| assign/accept 返回 403 | 用 admin/safety_officer token（employee 无权限）；admin 用 `scripts/init_admin.py` 创建 |
| rectify 返回 403 | 需责任人本人（`assignee_id=当前用户`）或 admin |
| 非法流转 400 | 对照状态机流转表；「待处理」只能派单，「处理中」只能整改，「待验收」才能验收 |
| 通知接口返回空 | Redis 未启动时的优雅降级，非故障；启动 Redis（6380）后可用 push→list 闭环 |
| vision 返回 503 | QWEN_API_KEY/QWEN_BASE_URL 未配置（D2 默认状态），填 `.env` 后重试 |
| SSE 测试无输出 | curl 需加 `-N`（禁用缓冲）实时查看流；真实调用需配置 DEEPSEEK_API_KEY |
