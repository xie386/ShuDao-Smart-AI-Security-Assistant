# PPT 生成 A+B 方案演示（D4 模块技术选型实证）

> 主题：《施工现场高处作业安全》安全讲座（贴合蜀道项目方向 A 场景）
> 生成时间：2026-08-13 ｜ 工具：全局 Python + python-pptx + playwright（系统 Chrome）

## 目的

用一份真实成品证明两条 PPT 生成路线：

| 方案 | 技术 | 页面 | 效果定位 |
|---|---|---|---|
| **A** | python-pptx 手绘商务模板（深蓝+金，母版式版式函数） | 封面/目录/内容×2/结尾（5 页） | 效果**下限**：离线、零依赖、稳定可复现 |
| **B** | HTML/CSS 设计（渐变+卡片+进度条）→ playwright 截图 → 嵌入 | 数据看板（1 页） | 效果**上限**：设计自由度拉满 |

## 文件

```
docs/ppt_demo/
├── demo_ppt.py                     # 演示脚本（A+B 完整实现）
├── 演示_高处作业安全_AB方案.pptx    # 成品（6 页，可直接打开）
└── assets/
    ├── page_b_data.html            # B 方案 HTML/CSS 源
    └── page_b_data.png             # B 方案截图（1280x720）
```

## 结论（供 D4 选型引用）

1. **A 方案完全够用且最稳**：python-pptx + 精心设计的版式函数（标题栏/分隔线/竖条/页码）
   即可达到"企业规范演示"水平；配合 3 套模板母版 + AI 填内容，任务书 P03-P07 全覆盖，演示零翻车。
2. **B 方案效果上限更高**：CSS 能实现渐变/数据卡片/图表等 A 难以企及的视觉；成本是
   playwright + Chrome 依赖（本项目已具备）与每页一张图的文件体积。
3. **落地建议**：内容页走 A（文字为主，AI 填充），封面/数据页走 B（视觉冲击），
   即"混合路线"——模板抽象 `PptTemplate` 预留两路插拔。
