## 3. 接口总览

| 序号 | 方法 | 路径 | 说明 | 鉴权 | 请求体 |
| --- | --- | --- | --- | --- | --- |
| 1 | GET | `/health` | 健康检查 | 无 | — |
| 2 | POST | `/api/auth/register` | 用户注册（角色固定 employee） | 无 | `RegisterRequest` |
| 3 | POST | `/api/auth/login` | 登录，签发 JWT | 无 | `LoginRequest` |
| 4 | GET | `/api/auth/me` | 当前登录用户信息 | Bearer Token | — |

### 3.1 数据契约（`src/schemas/auth.py`）

**RegisterRequest**

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| username | str | 3-64 位，`^[a-zA-Z0-9_]+$` | 登录名 |
| password | str | 6-64 位 | 密码，bcrypt 入库 |
| real_name | str? | ≤64 位，可空 | 真实姓名 |

**LoginRequest**：`username`、`password`（必填）。

**TokenResponse**（登录响应）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| access_token | str | JWT（HS256），默认 24h 有效 |
| token_type | str | 固定 `bearer` |
| user | UserOut | id / username / role / real_name / created_at |

> 安全约定：注册接口**不接收 role 字段**，新用户一律为 `employee`；admin/safety_officer 由初始化脚本创建。

## 4. 接口测试用例

### 4.1 GET /health — 健康检查

**用例 H-01 服务存活检查**

| 项 | 值 |
| --- | --- |
| 前置条件 | 服务已启动 |
| 请求 | `curl --noproxy '*' http://127.0.0.1:8000/health` |
| 预期状态码 | `200 OK` |
| 预期响应体 | `{"status":"ok","app":"蜀道智能安全助手","version":"0.1.0"}` |
| 校验点 | ① 状态码 200；② `status=ok`；③ `app` 与配置 APP_NAME 一致 |

---

### 4.2 POST /api/auth/register — 注册

**用例 A-01 注册成功（角色固定 employee）**

| 项 | 值 |
| --- | --- |
| 请求 | `curl --noproxy '*' -X POST http://127.0.0.1:8000/api/auth/register -H "Content-Type: application/json" -d "{\"username\":\"alice001\",\"password\":\"pass123456\",\"real_name\":\"爱丽丝\"}"` |
| 预期状态码 | `201 Created` |
| 预期响应体 | `{"id":1,"username":"alice001","role":"employee","real_name":"爱丽丝","created_at":"2026-08-12T10:00:00"}` |
| 校验点 | ① 状态码 201；② `role=employee`（安全约定）；③ 响应**不含** `hashed_password`；④ 返回自增 id |

**用例 A-02 用户名重复（409）**

| 项 | 值 |
| --- | --- |
| 前置条件 | 已存在 `alice001` |
| 请求 | 再次注册 `alice001` |
| 预期状态码 | `409 Conflict` |
| 预期响应体 | `{"detail":"用户名已存在"}` |

**用例 A-03 参数校验失败（422）**

| 项 | 值 |
| --- | --- |
| 请求 | ① username 仅 2 位；② password 少于 6 位；③ username 含非法字符（如 `abc-1`） |
| 预期状态码 | `422 Unprocessable Entity` |
| 预期响应体 | FastAPI 标准校验错误（`detail` 数组，含字段与错误说明） |
| 校验点 | 边界：username 3-64 位且仅 `[a-zA-Z0-9_]`；password 6-64 位 |

**用例 A-04 real_name 可省略**

| 项 | 值 |
| --- | --- |
| 请求 | 仅传 `{"username":"bob002","password":"pass123456"}` |
| 预期状态码 | `201` |
| 预期响应体 | `real_name` 字段为 `null` |

---

### 4.3 POST /api/auth/login — 登录

**用例 A-05 登录成功，签发 JWT**

| 项 | 值 |
| --- | --- |
| 前置条件 | 已注册 `alice001` |
| 请求 | `curl --noproxy '*' -X POST http://127.0.0.1:8000/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"alice001\",\"password\":\"pass123456\"}"` |
| 预期状态码 | `200 OK` |
| 预期响应体 | `{"access_token":"eyJhbGciOiJIUzI1NiIs...","token_type":"bearer","user":{"id":1,"username":"alice001","role":"employee",...}}` |
| 校验点 | ① 状态码 200；② `token_type=Bearer`（恒为小写 `bearer`）；③ `access_token` 非空，可用 [jwt.io](https://jwt.io) 解码验证 `sub=用户ID`、`role=employee`；④ 返回用户信息 |

**用例 A-06 密码错误（401，不泄露账号）**

| 项 | 值 |
| --- | --- |
| 请求 | 正确用户名 + 错误密码 |
| 预期状态码 | `401 Unauthorized` |
| 预期响应体 | `{"detail":"用户名或密码错误"}` |
| 校验点 | 用户名不存在与密码错误**统一 401**，不区分提示，防账号探测 |

**用例 A-07 用户名不存在（401）**

| 项 | 值 |
| --- | --- |
| 请求 | 未注册用户名 + 任意密码 |
| 预期状态码 | `401 Unauthorized` |
| 预期响应体 | `{"detail":"用户名或密码错误"}`（与 A-06 一致） |

---

### 4.4 GET /api/auth/me — 当前用户

**用例 A-08 携带有效 Token（200）**

| 项 | 值 |
| --- | --- |
| 前置条件 | 通过 A-05 获取 `access_token` |
| 请求 | `curl --noproxy '*' http://127.0.0.1:8000/api/auth/me -H "Authorization: Bearer <token>"` |
| 预期状态码 | `200 OK` |
| 预期响应体 | `{"id":1,"username":"alice001","role":"employee","real_name":"爱丽丝","created_at":"..."}` |
| 校验点 | 返回的用户与 Token 中 `sub` 一致 |

**用例 A-09 未携带 Token（401）**

| 项 | 值 |
| --- | --- |
| 请求 | 无 `Authorization` 头 |
| 预期状态码 | `401 Unauthorized` |
| 预期响应体 | `{"detail":"未提供认证令牌"}` |

**用例 A-10 无效/过期 Token（401）**

| 项 | 值 |
| --- | --- |
| 请求 | `Authorization: Bearer <伪造或篡改的token>` |
| 预期状态码 | `401 Unauthorized` |
| 预期响应体 | `{"detail":"无效或过期的令牌"}` |
| 校验点 | 非法签名 / 过期 token 均被拒绝 |

## 8. 附录：常见问题

| 问题 | 处理 |
| --- | --- |
| curl 请求被代理拦截/超时 | 加 `--noproxy '*'` |
| 启动报 MySQL 连接错误 | 检查 `shudao_safety` 库及 `database/schema.sql` 是否已建表 |
| `/api/auth/register` 期望传 role | 属误用：安全约定注册角色固定 employee，管理员走 `init_admin.py` |
| Token 过期 | 默认 24h 有效，`ACCESS_TOKEN_EXPIRE_MINUTES` 可调；重登获取新 Token |
| AI 脚本报「API_KEY 未配置」 | D1 可接受；在 `.env` 填 `DEEPSEEK_API_KEY` 后重跑 |
